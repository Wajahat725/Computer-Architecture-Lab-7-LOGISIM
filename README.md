# Computer Architecture Lab - Task 7 (Logisim)

This repository contains the circuit design files for **Task-7** of the Computer Architecture Lab, created using **Logisim**. The focus of this task is on fundamental combinational circuits such as logic gates, encoder, decoder, multiplexer, and 4-bit adder/subtractor.

## 🧠 Lab Task Overview

**Topic:** Combinational Circuits  
**Tool Used:** [Logisim](http://www.cburch.com/logisim/) (Digital Circuit Simulator)

**Circuits Included:**
- Basic Logic Gates (AND, OR, NOT, NAND, NOR, XOR, XNOR)
- Encoder
- Decoder
- Multiplexer
- 4-bit Adder
- 4-bit Subtractor
- Half Adder
- Full Adder
- Subtractor
- Demultiplexer

These circuits form the foundational building blocks of digital electronics and are essential for understanding computer architecture.
